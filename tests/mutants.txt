# Mutations applied to the scripts of scripts/ by tests/mutation_check.sh.
#
# One mutation per line:  name@@script in scripts/@@test file(s) in tests/bats/@@sed -E expression
#
# The expression must change the script into valid bash, and the tests listed
# must fail with the mutated script. Lines starting with # and empty lines are
# ignored. Use only the portable subset of sed (-E, no \t): it runs with GNU and
# BSD sed.
#
# One mutation per decision that defines the checks (a wrong name, a placeholder
# version, a missing marker or extra must fail; a valid archive must pass). Each
# expression is anchored on a short token (an operator, a name), not on a whole
# line, so that a refactoring keeps it valid.
